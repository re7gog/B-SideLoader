# GEMINI.md

Instructions for Gemini CLI when working in this repository.

This project's full guidance for **all** AI coding agents lives in one file:
[AGENTS.md](AGENTS.md) at the repository root. Read it in full before your first change and
follow it — especially the *Code search* section: symbol searches go through `ast-index` before
any grep. If your Gemini CLI version already loads `AGENTS.md` as a context file, this pointer is
redundant but harmless; keep new guidance in AGENTS.md, never here.
